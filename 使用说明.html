FolderScope · 双语磁盘空间分析工具

v1.1.0 · Windows x64

FolderScope 是一款开源的 Windows 磁盘空间分析工具，支持简体中文和英文界面。源码与下载：grantyxy/FolderScope。

启动与语言

双击同目录下的 FolderScope.exe。请把 FolderScope.exe.config 与程序放在一起。使用系统自带的 .NET Framework 4.8，不需要 Python、Node.js 或额外服务。默认以普通用户权限运行；需要 MFT 扫描时，可点击功能区“工具 → 管理员运行”。

右上角 中文 / EN 可即时切换简体中文与 English，扫描结果保留，语言选择自动记住。默认简体中文；文件名、文件路径、扩展名和所有者账号保持原值。选项中也可以设置语言和浅色、深色主题。

开始分析

  1. 在路径栏输入本地路径或 UNC 共享路径，点击“开始”；也可以点击“浏览”选择文件夹。
  2. 多个路径用“多个路径”窗口输入，每行一个。重复或相互包含的路径会合并，避免重复扫描。
  3. 扫描期间可暂停、继续或停止。停止后保留部分结果，并明确标记。无权限、重解析点、深度截断等情况显示在“事件日志”。
  4. “明细”中双击文件夹进入下一级。点击列标题排序，右键打开操作菜单；“显示列”可选择更多时间、路径、属性列。
  5. 柱状图、饼图、旭日图、文件夹矩形图均使用当前目录数据。双击图中的文件夹区域可进入该文件夹。

“大小”是文件逻辑字节数；“占用空间”通过系统元数据查询。数值单位按 1024 换算。硬链接按目录项计数，不代表去重后的卷物理占用；文件系统元数据、系统保留空间和扫描不到的内容也不计入目录文件大小。目录重解析点不跟随；文件重解析点不读取内容，其占用空间显示为 0 并记录为未知，不能理解为实际没有占用。修改扫描过滤规则后需要重新扫描。

扫描引擎

默认尝试本地 NTFS MFT 直接读取，通常需要管理员权限。普通权限、网络位置、不支持的文件系统或读取失败时回退到并行目录枚举；状态栏显示实际使用的引擎。可以在选项中关闭 MFT。MFT 模式可能读取整个卷的 MFT 后再筛选目标目录，因此扫描很小的文件夹时不一定更快。

报告与搜索

“文件报告”包括最大、最旧、最新、临时、重复、类型、分类、属性、所有者、大小、名称、时间、深度、年份、非业务文件共 15 类，另有空文件夹和超长路径。文件所有者默认不采集；需要时先在选项中开启，再扫描。报告条数设为 0 可显示全部。

重复文件支持“名称”“名称 + 大小”“名称 + 大小 + 修改时间”及 SHA-256 内容校验。前三种是元数据匹配，不能证明内容相同。“每组保留首项，选择其余”只改变选中状态，不会自动删除。内容校验会读取候选文件，遇到读取失败会报告错误。

搜索支持通配符、正则表达式，以及大小、占用空间、深度、路径长度、名称长度、文件数、修改距今天数、属性、所有者等规则。当前实现中，多个包含规则按“或”组合，排除规则优先；数值大小单位是字节。“搜索当前扫描结果”不重新扫描，“先扫描目录”重新采集。报告和搜索均限定在输入路径内。

扫描过滤中的文件规则作用于文件；文件夹规则会决定是否进入整个分支，因此文件夹包含规则也可能剪去不匹配的上层目录。文件夹总大小、占用空间和文件数在遍历前尚不可用，需先扫描后在搜索中使用。过滤后没有匹配文件的目录不会被误报为真正的空文件夹。

保存、比较与导出

“保存结果”保存 .fsscan 快照。快照包含元数据，不包含原文件内容，可离线查看、搜索与比较；离线快照禁用修改真实文件的操作。该格式是 FolderScope 自有格式。

可导出 XLSX、CSV、HTML、PDF、XML、TXT；图表可保存 PNG。XLSX 是标准工作簿，CSV 对文件名等文本做公式注入防护。PDF 使用位图页面以保留中文显示，文字不能直接搜索或复制；很长的路径会在 PDF 中省略，完整路径请看 XLSX、CSV 或 XML。“打印”提供系统打印预览。

1.1 新功能

“选项 → 扫描 → 跳过云端占位文件和目录”可按系统云属性跳过占位内容；开启后采用目录枚举。内容重复检测不会把被跳过的云端、重解析点或不完整文件当作已校验，报告状态栏和事件会提示。大文件先比较头尾各 64 KiB，仍可能相同的文件再完整计算 SHA-256；文件发生变化或读取失败会报告错误。

XLSX 超出每张表 1,048,575 条数据时自动分表，每表保留表头、冻结和筛选。“工具 → 磁盘历史 → 容量预测”使用同一卷最近 30 天、至少 3 个独立时点且跨度 24 小时的数据，估算每日增长和可用空间耗尽日期。缺少卷身份的旧版历史不参与；更换卷或容量变化后重新积累。刷新历史或完成扫描会记录采样，程序不会自动创建采样计划。预测包含可用空间与配额变化，不能保证实际日期。

路径索引暂不支持仅大小写不同的重名路径，遇到冲突会记录被省略项并标为部分扫描；硬链接仍按路径计数。MFT 异常记录回退目录枚举，不能把合成记录测试理解为任意磁盘场景均已验证。

文件操作

在结果中选择真实文件后，右键可打开、定位、复制路径、查看属性、复制、移动、重命名、移入回收站或创建 ZIP。修改操作前会检查文件是否在扫描后变化。删除与移动要求在应用内确认；网络位置是否支持回收站由 Windows 处理，不会由本程序静默改为永久删除。ZIP 不提供密码加密，也不会覆盖已有压缩包。遇到复制或压缩中途失败时，目标可能保留已生成的部分内容，应根据错误提示核对。

任务计划、网络与邮件

“任务计划”支持一次、每天或每周，使用 Windows 任务计划程序，要求当前 Windows 用户已登录。可以输出报告并保存快照；移动程序目录后需要重新创建任务。“立即执行”会按填写内容真正运行；勾选邮件时会发送邮件。

“网络共享”可枚举指定服务器的共享，使用当前 Windows 用户已有凭据。程序不管理网络密码。SMTP 在选项中配置，密码使用当前 Windows 用户的 DPAPI 加密保存。常见配置是端口 587 配合 STARTTLS；未实现隐式 TLS 465。只有点击发送、执行已启用邮件的作业或用户创建的计划任务时才发送邮件。

数据与源码

设置、磁盘历史、计划作业定义、文件操作日志和错误日志保存在 %LOCALAPPDATA%\FolderScope。代码在 src 目录，build.ps1 可使用 Windows 自带的 .NET Framework C# 编译器重建。

命令行接口

以下是可选的自动化接口，普通使用不需要终端。多个路径用 | 分隔。

FolderScope.exe --scan "D:\Data" --snapshot "D:\Reports\scan.fsscan" --export "D:\Reports\details.xlsx"
FolderScope.exe --scan "D:\Data|E:\Data" --report "Largest Files" --export "D:\Reports\large.csv"
FolderScope.exe --scan "D:\Data" --report "Duplicate Files" --duplicate-mode "Content (SHA-256)" --export "D:\Reports\duplicates.html"
FolderScope.exe --job "C:\Path\job.xml"

命令行报告名称使用固定英文标识符，配置文件格式可以参考源码；退出码 0 表示运行结束，1 表示错误，3 表示取消。扫描事件会写入相邻的 .events.txt 文件，不应仅凭退出码判断整个目录是否完整可读。
