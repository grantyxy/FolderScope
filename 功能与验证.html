FolderScope 功能与验证

v1.0.0-preview.1 · 2026-10-23 · Windows x64

FolderSizes 的开源替代品，基于 C# / .NET Framework 完全重写，支持简体中文和英文。本项目采用独立实现；“完全重写”不表示所有功能、界面细节和文件格式均与 FolderSizes 相同。

本次从发布源码重新编译，在 Windows 11 x64 普通用户权限下运行内置自检，结果为 29 / 29 项通过。详细结果见 验证结果.txt。下表区分代码已有能力和本次实际验证范围。

范围当前实现验证与限制
双语与界面简体中文 / English、浅色 / 深色主题、功能区、路径栏、目录树、明细。自检覆盖双语资源和导出标签。本次未重新进行完整图形界面验收。报告窗口短暂空白现象已有反馈，未完成修复验收。
扫描NTFS MFT 读取与并行目录枚举；多路径、过滤、暂停、取消和事件日志。普通权限下验证了枚举统计、路径合并、过滤、取消和长中文路径。MFT 一般需要管理员权限，条件不满足时回退；MFT 复杂场景和大规模性能尚未全面验证。
图表柱状图、饼图、旭日图、矩形树图，支持下钻与 PNG 导出。代码包含实现，本次未重新逐一验证窗口交互。未实现完整停靠 / 浮动面板系统。
报告与搜索17 类报告，元数据与 SHA-256 重复检测；规则搜索和扫描过滤。报告生成、重复匹配、规则优先级、目录范围与空目录判断已自检通过。包含规则按 OR 组合，尚无完整复杂条件组。
快照与导出.fsscan 快照、比较、历史；XLSX、CSV、HTML、PDF、XML、TXT 导出。快照往返、差异和导出基本结构通过自检。自有快照格式不兼容 FolderSizes；PDF 为位图，文字不可搜索或复制。
文件操作复制、移动、重命名、回收站、ZIP 归档与操作日志。受控样本的复制和 ZIP 通过自检。未针对用户现有文件执行移动或删除测试。ZIP 不提供加密。
自动化与网络命令行、计划任务、共享枚举与 SMTP 邮件。本次验证作业 XML 和命令行本地扫描导出；真实网络共享、邮件投递、定时触发尚未验收。

大小合计不能直接解释为卷的去重物理占用；硬链接、文件系统元数据、压缩 / 稀疏文件、重解析点和权限均可能影响结果。请结合事件日志判断扫描是否完整。

自动构建与测试结果可查看 GitHub Actions。采用 MIT 许可证；完整源码与构建脚本在项目仓库中。
